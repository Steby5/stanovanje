# Trigger words.  A post is sent to Discord when it matches at least ONE line
# here and no "!" exclusion line.
#
# Matching ignores case and diacritics ("zelim" matches "Želim"), and plain
# terms also match declined forms - "ljubljana" matches "v Ljubljani",
# "garsonjera" matches "garsonjero".  Short words stay literal.
#
#   stanovanje             matches stanovanja, stanovanju, stanovanje...
#   oddam + soba           AND: both parts must appear in the post
#   "oddam stanovanje"     exact phrase, no stemming
#   =soba                  whole word only (won't match "posoda")
#   re:\d{3,4}\s?(eur|€)   regular expression
#   !agencija              EXCLUSION - skip any post containing this
#   @lj                    ANY one of the terms defined by "@lj = a, b, c"
#
# With no trigger words at all, this person receives nothing (rather than
# everything) - so a newly added user isn't buried under every post.
# Edit this file while the watcher is running; changes apply on the next cycle.
# Test a line without touching Facebook:
#   python main.py test-keywords "Oddam lepo sobo v Ljubljani, 400 EUR"

# ---- where ---------------------------------------------------------------
# Requiring the literal word "ljubljana" loses listings, because people name
# the district instead: "Oddam sobo, Bezigrad" never says Ljubljana at all.
# An alias matches ANY of its terms, so use "+ @lj" wherever you would have
# written "+ ljubljana".  Add your own areas; delete the ones you'd not take.
@lj = ljubljan, bezigrad, siska, trnovo, moste, sentvid, kodeljevo, fuzine, dravlje, koseze, vodmat, crnuce, stozice, jezica, zalog, rudnik, prule, krakovo, mirje, galjevica, kosese, "rozna dolina", "novo brdo", =vic, =vicu, =vica, =vicem, =center, =centru, =centra, =centrom, =btc
